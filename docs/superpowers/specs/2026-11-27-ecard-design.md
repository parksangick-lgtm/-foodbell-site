# 전자명함(웹 명함 한 장) 설계 — 2026-11-27

사장님 요청(2026-11-27, 집 PC): "사이트를 기본베이스로 하여 전자명함을 만들려구해. 제미나이와 협력하고 관리자를 불러서 만들어줘."

## 1. 왜 · 무엇

- 사장님 명함을 휴대폰에서 여는 화면 한 장으로 만든다. 주소를 카톡 · 문자로 보내면 받는 사람이 열어서 바로 전화 · 문자 · 카카오톡을 하고, 연락처를 저장하고, 다른 사람에게 다시 전달할 수 있다.
- 사이트(foodbell.kr)의 색 · 글꼴 · 정보 · 문구를 그대로 쓴다. 새 사실 · 새 약속은 넣지 않는다.

**목표**
- 휴대폰 한 화면에 명함이 보이고, 누르는 것 여섯(전화 · 문자 · 카카오톡 · 연락처에 저장 · 명함 전달하기 · 홈페이지 보기)이 각각 제 일을 한다.
- 카톡방에 주소를 붙이면 명함 모양 그림이 같이 뜬다.

**하지 않는 것** (사장님이 고르지 않음)
- 명함 사진 따로 만들기, QR, 주소 · 영업시간 · 이메일 · 사업자번호 표시, 상차림 사진.
- 가격, 방문 통계, 로그인, 카카오 개발자 키가 필요한 '카카오톡 공유' 단추.
- 사이트 첫 화면(`index.html`)에서 명함으로 가는 링크 — 요청에 없음.

**이렇게 되면 실패**
- 명함과 사이트의 전화 · 문자 · 카카오톡 주소가 서로 달라지는 것.
- 폭 320(사장님 휴대폰) · 360 · 390 에서 옆으로 넘치거나 글자가 잘리는 것.
- 사이트에 없는 문구 · 가격이 들어가는 것.

## 2. 검토한 방법

| 방법 | 좋은 점 | 나쁜 점 |
|---|---|---|
| **가. 사이트 안 웹 명함 한 장** (고름) | 버튼이 눌린다 · 고치면 이미 보낸 것도 바뀐다 · 브랜드 그대로 | 받는 사람이 링크를 눌러야 한다 → 미리보기 그림으로 보완 |
| 나. 명함 사진 한 장 | 카톡방에서 바로 보인다 | 누를 수 없다 · 고치면 다시 보내야 한다 |
| 다. 바깥 명함 서비스(리멤버 등) | 만들 것이 없다 | 그쪽 로고 · 광고, 브랜드 색을 못 쓴다 |

클로드 · 제미나이(gemini-3.6-flash) 카운슬 2026-11-27: 둘 다 '다'는 반대, '가'를 기본으로. 제미나이는 '나'도 처음부터 같이 하자고 했고, 사장님은 **가** 를 골랐다(2026-11-27).

## 3. 사장님이 정한 것 (2026-11-27)

- 형태: 웹 명함 한 장. 카톡방에 명함 모양 그림이 뜨게.
- 더 넣을 것: **연락처에 저장 버튼**, **명함 전달하기 버튼**.
- 모양: **글자와 낙관만**(사진 없음).

## 4. 클로드가 정한 것 (사장님이 바꿀 수 있음)

- 주소: `https://foodbell.kr/card.html` (파일 `card.html`).
- 검색에는 안 잡히게(`noindex`) — 사이트 첫 화면과 내용이 겹친다.
- 주소록에 저장되는 이름: **푸드벨 박상익** (전화가 오면 이 이름이 뜬다). 회사 `푸드벨(박상익출장음식)`, 직함 `대표`, 휴대폰, 홈페이지, 메모 `시제상차림 · 제사상차림 · 출장음식`. 이메일 · 주소는 넣지 않는다.
- 눈에 띄는 버튼은 전화(버건디 채움) 하나, 문자 · 카카오톡은 테두리 버튼. 셋을 한 줄에.
- 휴대폰 아래 고정 막대(전화 · 문자)는 두지 않는다 — 화면 자체가 버튼이라 겹친다.
- '명함 전달하기'는 휴대폰의 공유 창을 쓴다. 공유 창이 없는 곳(카톡 안 브라우저 · PC)에서는 주소를 복사하고 안내를 보인다.
- 색 · 글자 크기 · 간격은 `css/style.css` 의 `:root` 값만 쓴다(`css/style.css?v=` 를 불러 쓴다 — `privacy.html` 과 같은 방식).

**만든 뒤 더 정한 것 (2026-11-27, 관리자 보고를 받고 메인이 정함)**
- 큰 전화번호는 사이트의 큰 번호(`.contact__cta-number`)와 같게 곱은바탕 700. 미리보기 그림의 번호도 같은 글꼴로 — 가운데 정사각형으로 잘려도 번호가 안 잘린다(번호 자리 302~899, 정사각형 285~915).
- `foodbell.vcf` 의 줄 끝: 이 PC 는 `core.autocrlf=true` 라 깃이 LF 로 바꿔 저장하려 했다 → `.gitattributes` 에 `*.vcf -text`. 시험에 그 줄을 지키는 것 하나 더함.
- 주소록 이름 칸: `N:;푸드벨 박상익;;;`(성 자리를 비움 — 휴대폰이 순서를 바꾸지 않게) · `FN:푸드벨 박상익`.
- 전화 · 문자 · 카카오톡은 그림을 글자 위에(폭 320 에서 옆으로 두면 '카카오톡' 이 넘침). 넓은 단추 높이 52px.

**사장님이 미리보기를 보고 바꾼 것 (2026-11-27 오후): "너무 허접해. 사진을 넣고 해줘"**
- 3절의 '글자와 낙관만' 은 물렀다. 맨 위에 상차림 사진(`images/card-photo.jpg` 960×640 — 사이트 대표 사진 `images/hero-table.jpg` 에서 자른 것, 촬영정보 없음)을 넣고,
  그 아래 흰 종이(명함)가 사진에 48px 걸쳐 올라오며, 낙관이 종이 윗선에 걸친다. '대표' 와 이름은 한 줄에. 맨 아래 '홈페이지 보기' 는 가운데 · 화살표.
- 카톡 미리보기 그림(`images/og-namecard.jpg`)도 왼쪽 사진 · 오른쪽 글자로 바꿨다.
- 큰 전화번호는 폭 320 에서 두 줄로 꺾이지 않게 `min(var(--text-3xl), 9vw)` · `nowrap`.

- 낙관: 버건디(`--color-primary`) 네모 안에 `푸 / 드 / 벨` 세로, 곱은바탕 700, 글자색 미색.
- 이름 · 상호는 곱은바탕 700, 나머지는 본문 글꼴 400, 버튼 · 라벨은 600.
- 아이콘은 인라인 SVG 선 아이콘(전화 · 카카오톡은 `index.html` 의 것을 그대로, 문자 · 저장 · 전달은 같은 굵기 1.6 으로 새로). 이모지 · 특수문자 아이콘 금지.
- PC 처럼 넓은 화면에서는 가운데에 폭 480px 까지.
- 바깥 글꼴 스타일시트(구글 폰트 · jsdelivr)는 화면을 막지 않게 부른다(`call.html` 의 `media="print" onload` 방식) — 약한 신호에서도 글자가 먼저 뜬다.

## 7. 가정 — 아직 확인 못 한 것

| 가정 | 틀리면 | 확인 방법 |
|---|---|---|
| 카톡 안 브라우저에서 `foodbell.vcf` 링크가 연락처 저장 화면으로 이어진다 | 저장 버튼이 안 먹는다 → 버튼 아래 안내 글과 큰 번호가 대신한다 | 올라간 뒤 사장님 갤럭시에서 '나와의 채팅'에 주소를 보내 눌러 본다. 아이폰은 가진 분께 부탁 |
| 휴대폰 공유 창(`navigator.share`)이 카톡 안 브라우저에 없을 수 있다 | 주소 복사 + 안내 글로 넘어간다(설계에 넣음) | 위와 같이 눌러 본다 |
| 버셀이 `.vcf` 를 연락처 파일 형식으로 내준다 | 글자로 열린다 → `vercel.json` 에 형식 한 줄(그때 사장님께 여쭘) | 올라간 뒤 `curl -sI https://foodbell.kr/foodbell.vcf` |
| 카톡은 미리보기 그림을 오래 붙잡는다 | 그림을 바꿔도 옛 그림이 뜬다 | 그림을 바꿀 때는 파일 이름도 바꾼다 · 카카오 디버거에서 비운다 |
