# 옵시디언 저장

방금 만든 결과물을 옵시디언 볼트에 마크다운 노트로 저장한다.

## 먼저 알아야 할 것

옵시디언 볼트는 특별한 프로그램 전용 형식이 아니라 **`.md` 파일이 들어 있는 그냥 폴더**다.
그래서 저장 = 그 폴더에 마크다운 파일을 쓰는 것. 옵시디언 앱이 꺼져 있어도 저장되고,
앱을 켜면 새 노트가 자동으로 나타난다.

**중요한 제약**: 볼트는 사용자 PC에 있는 폴더다. 클라우드(웹/GitHub Actions)에서 도는
세션은 그 폴더에 닿을 수 없다. 이 스킬은 **사용자 본인 컴퓨터에서 돌 때만** 실제로
저장된다. 클라우드 세션이면 저장하지 말고, 저장할 내용을 화면에 보여준 뒤
"이건 PC에서 실행해야 볼트에 들어갑니다"라고 알려준다.

## 순서

### 1. 볼트 경로 확인

이 순서로 찾는다.

스크립트가 알아서 찾으므로 **보통은 사용자에게 묻지 않는다.** 찾는 순서는:

1. 사용자가 방금 말한 경로 (`--vault`)
2. 프로젝트 `.env` 파일의 `OBSIDIAN_VAULT`
3. `~/.claude/obsidian_vault.txt` (한 번 등록해 두면 어느 폴더에서든 쓰인다)
4. **옵시디언 설정 파일에서 자동 탐색** — 옵시디언은 열어 본 볼트 목록을
   `obsidian.json` 에 적어 둔다. 지금 열려 있는 볼트를 우선 쓴다.
5. 다 실패했을 때만 → `--list-vaults` 로 확인해 보고, 그래도 없으면 물어본다:
   "옵시디언 볼트 폴더 경로를 알려주세요. (옵시디언 왼쪽 아래 볼트 이름 클릭 →
   '다른 보관소 열기' 에서 경로를 볼 수 있습니다)"

경로를 받으면 아래로 등록해 둔다. 그래야 다음부터 안 물어보고, 다른 작업
폴더에서도 그대로 쓸 수 있다.

```bash
python obsidian_save.py --set-vault "볼트폴더경로"
python obsidian_save.py --set-vault auto      # 자동으로 찾은 볼트를 등록
```

### 2. 본문 준비

- 본문은 **속성(`---`) 블록 없이** 순수 마크다운으로만 만든다. 속성은 스크립트가 붙인다.
- 맨 위 `# 제목` 은 넣지 않는다. 옵시디언은 파일 이름을 제목으로 쓴다.
- 다른 노트와 이어 주면 좋은 곳에는 `[[노트이름]]` 형태의 내부 링크를 넣어도 된다.

### 3. 저장 실행

스크립트는 `~/.claude/skills/obsidian-save/obsidian_save.py`(설치된 경우) 또는
`src/obsidian_save.py`(이 저장소 안) 에 있다. 있는 쪽을 쓴다.

```bash
python ~/.claude/skills/obsidian-save/obsidian_save.py \
  --title "노트 제목" \
  --folder "유튜브 요약" \
  --tags "유튜브,요약,별빛마실" \
  --source "https://youtu.be/VIDEO_ID" \
  --file /tmp/note.md
```

본문은 `--file` 로 넘기거나 표준입력(파이프)으로 넘긴다. 본문이 길면 임시 파일에 쓴 뒤
`--file` 로 넘기는 쪽이 안전하다.

주요 옵션:

| 옵션 | 뜻 |
| --- | --- |
| `--title` | 노트 제목. 이게 파일 이름이 된다 (필수) |
| `--folder` | 볼트 안 하위 폴더. 없으면 자동으로 만든다 |
| `--tags` | 태그, 쉼표로 구분. 공백은 `-` 로 바뀐다 |
| `--source` | 출처 링크(유튜브 URL 등) |
| `--vault` | 볼트 경로 직접 지정 (기본값은 `OBSIDIAN_VAULT`) |
| `--date-prefix` | 파일 이름 앞에 `2026-09-05 ` 처럼 날짜 붙이기 |
| `--auto-number` | 폴더의 기존 번호를 이어서 `17-` 처럼 붙이기 (번호로 정리된 폴더용) |
| `--list-vaults` | 옵시디언에 등록된 볼트를 찾아서 보여주기 |
| `--mode` | 이름이 겹칠 때: `new`(기본, 새 이름) / `overwrite` / `append` |
| `--dry-run` | 저장하지 않고 결과만 보여주기 |

### 4. 결과 보고

저장된 **전체 경로**를 사용자에게 알려준다. 여러 개면 목록으로 정리한다.

## 폴더·태그 기본값

사용자가 따로 말하지 않으면 아래 기준으로 정하고, **정한 값을 보고할 때 같이 알려준다.**

| 저장할 내용 | 폴더 | 태그 |
| --- | --- | --- |
| 유튜브 영상 요약 | `유튜브 요약` | `유튜브, 요약` |
| 쇼츠 대본 / 내레이션 | `쇼츠 대본` | `쇼츠, 대본, 별빛마실` |
| 사연 소재 / 아이디어 | `사연 소재` | `소재, 별빛마실` |
| 채널 기획 · 전략 메모 | `채널 기획` | `기획` |
| 그 외 | 볼트 최상위 | 내용에 맞는 태그 1~3개 |

시니어 쇼츠 채널 **별빛마실** 관련 결과물에는 `별빛마실` 태그를 항상 같이 붙인다.

## 여러 개를 한 번에 저장할 때

풀패키지(대본 + 제목안 + 썸네일 문구 + 이미지 프롬프트)처럼 덩어리가 여러 개면,
**기본은 노트 하나**로 합쳐서 저장한다. 섹션(`##`)으로 나누면 옵시디언에서 접었다 펼 수
있어서 찾기 쉽다. 사용자가 "따로따로 저장해줘"라고 하면 그때 나눈다.

## 주의할 점

- 파일 이름에 `\ / : * ? " < > |` 는 못 쓴다. 스크립트가 알아서 공백으로 바꾸지만,
  제목을 정할 때 애초에 안 쓰는 게 깔끔하다.
- 이미 있는 노트를 **덮어쓰기 전에는 반드시 사용자에게 확인**한다. 기본 `new` 모드는
  겹치면 `제목 2.md` 로 새로 만들어서 안전하다.
- 볼트 바깥 경로(`../`)에는 저장할 수 없다. 스크립트가 막는다.
- 볼트가 iCloud·Dropbox 등으로 동기화 중이면, 저장 직후 다른 기기에 뜨기까지 몇 초
  걸릴 수 있다.
