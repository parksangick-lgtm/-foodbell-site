# coding-study

## 4번 스킬 사용 시 적용 규칙

1. 각 섹션 코드블록 안에 제목 포함
   - 각 코드블록의 맨 위 줄에 섹션 제목을 넣습니다.
   - 예: `1) 이름의 유래`
   - 이렇게 하면 메모장에 복사해도 어떤 섹션인지 바로 확인할 수 있습니다.

2. 타이핑 연습용 요약본 제목 변경
   - 기존의 `타이핑 연습용 요약본` 대신, 다룬 단어명을 포함한 제목을 사용합니다.
   - 예: `타이핑 연습용 요약본 — 하이퍼텍스트`
   - 예: `타이핑 연습용 요약본 — 서버`

## 적용 예시

```text
1) 이름의 유래
...내용...
```

```text
타이핑 연습용 요약본 — 하이퍼텍스트
...내용...
```
이렇게 답변해줘
