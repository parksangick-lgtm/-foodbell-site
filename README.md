# 푸드벨 (FoodBell) — 시제상차림·제사상차림 출장음식 전문

정적 HTML/CSS/JS로 제작된 시제·제사음식 출장 서비스 소개 사이트입니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.
(VSCode를 쓴다면 Live Server 확장을 사용하면 편합니다.)

## 폴더 구조

```
galleypark/
├─ index.html        # 메인 페이지 (홈/소개/서비스/갤러리/문의 전체 포함된 단일 페이지)
├─ css/style.css      # 전체 스타일
├─ js/main.js         # 모바일 메뉴, 탭 전환, 갤러리 라이트박스, 스크롤 인터랙션
├─ images/            # 구글 드라이브에서 가져온 실제 시제상/제사상 사진
└─ README.md
```

**시제상차림·제사상차림·출장음식 전문** 서비스로 사이트를 구성했습니다.
"서비스" 섹션은 두 개 탭으로 구성됩니다:

- **체육대회·모임·마을잔치** — 체육대회, 마을잔치·경로잔치, 모임·야유회 도시락, 다과 세트

※ "종중 시제·묘사상"과 "제실·사당 시제상"은 같은 카테고리로 병합했습니다 ("재실"은 "제실"로 오타 수정).

## 실제 사진 사용 안내

`images/` 폴더의 사진은 구글 드라이브의 "푸드벨시제", "푸드벨 제사" 폴더에서 가져온
**실제 상차림 사진**입니다 (`hero-table.jpg`, `gallery-1.jpg` ~ `gallery-7.jpg`).

- 사진은 원본에서 화면 방향을 보정하고 웹에 맞게 리사이즈·압축했습니다.
- **개인정보 보호를 위해 다음 사진은 의도적으로 제외했습니다**: 고인의 영정사진이나
  이름·생몰년이 적힌 묘비가 그대로 노출된 사진(예: 공원묘지·골프장·야산에서 찍은 개별 가정 성묘 사진 3장).
  이런 사진은 특정 가족의 개인정보가 담겨 있어 고객 동의 없이 공개 홍보에 사용하기 부적절하다고
  판단했습니다. 얼굴·이름이 나오지 않는 문중 시제상, 제실 상차림, 가정 제사상 근접 사진만 선별했습니다.
- **체육대회·마을잔치 관련 실제 사진은 드라이브에서 찾지 못했습니다.** "박태현사진", "차귀란" 폴더를
  확인했지만 해변·식사 자리에서 찍은 개인적인 인물 사진(얼굴이 그대로 나온 사적인 사진)이라 이 사업의
  실제 행사 사진이 아니었고, 공개 홍보에 쓰기에도 적절하지 않아 사용하지 않았습니다. 대신 같은 탭에
  이모지 아이콘을 유지했습니다. 실제 체육대회·마을잔치 사진이 있으면 전달해주세요.
- 대신 "시제·제사음식" 탭에 실제 사진 한 장(`gallery-7.jpg`, 실내 제사상 전체 상차림)을 추가해
  갤러리를 더 다양하게 구성했습니다.

## 텍스트 가독성

요청에 따라 전체 본문 글자 굵기를 2단계 올리고(기본 400 → 600), 본문 글자색도 더 짙게
조정해 화면에서 더 선명하게 보이도록 했습니다 (`css/style.css`의 `body`, `--color-ink`,
`--color-ink-soft`).

## 지금도 예시(placeholder)로 남아있는 항목

- **가격/견적**: 시제·제사상은 위(位)의 수·장소·구성에 따라 편차가 커서 "상담 후 안내"로
  표기했습니다. 대략적인 가격대가 있다면 알려주시면 반영하겠습니다.
